# Evidence — Stage 2, Systematic

**Systematic means AI is a team practice**: named accounts, shared and
owned assets, champions with time, spend visible, AI output consciously
reviewed. It is the middle of three stages — after **Ad hoc** (AI as a
personal tool) and before **Compounding** (AI as the operating model); see
[README.md](README.md).

One row per question of the [maturity model](../maturity-model.md). Keep
these continuously green; each row names the artifact and the mechanism
that produces it. Artifact names must be self-explanatory; where data is
sensitive, a substantive written account replaces the screenshot.

| question | evidence artifact | produced by |
|---|---|---|
| Where does AI act? | current-quarter phase coverage table (../templates/phase-usage-table.md) showing AI in most stages | quarterly review with each role |
| Who does it act as? | tool accounts mapped to people; sample output with a name on it | tool admin + spot check |
| What does it cost? | per-tool spend report, monthly | billing export |
| How good is its output? | review notes on a sample of AI-produced changes | normal PR review, tagged |
| Does capability compound? | repo of prompts/rules/runbooks with owners and recent commit dates | the shared repo itself |
| Who carries it? | filled champions table (../templates/ai-champions.md) with recent activities | team roster |

Update the self-assessment quarterly or the validation expires.
