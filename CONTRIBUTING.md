# Contributing

This blueprint practices what it preaches — contributions ride the same
rails it describes.

- **PRs only**, conventional commit messages, one concern per PR.
- **Disagree by superseding**: a change to a decision arrives as a
  superseding ADR with your context, never as a silent edit to the old one.
- **Sanitization is a hard gate**: no client, vendor, product or person
  names from any real engagement — in files *or commit metadata*. Anecdotes
  stay anonymous and non-identifying.
- **Lessons need evidence**: a new lessons-learned entry carries the error
  text, command or numbers that prove it happened.
- **Keep documents small**: one topic per file; split with an index past
  ~6k characters.
- Checked links, rendered Mermaid, consistent stage naming
  (Stage 1 — Ad hoc / Stage 2 — Systematic / Stage 3 — Compounding).
