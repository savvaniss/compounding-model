# Working agreement — humans and agents, same rules

- **Tickets belong to the team.** Agents never open tickets unasked; work is
  tracked as comments on the ticket it belongs to.
- **Narration is mandatory**: before — problem and plan; during — progress;
  after — a validation guide so the requester can check the work themselves.
- **Links or it didn't happen**: whoever triggers a run hands over link + id.
- **Waits name every exit** (success, failure, timeout) and act on results,
  not status pages. After a merge, deploy; after a deploy, verify; stop only
  where a decision is genuinely human.
- **Assets registered at birth**; **incidents become written lessons with
  evidence**; the second engineer never pays for the first one's education.
- Secrets have one home; nothing web-facing ships anonymous; verify with an
  unauthenticated request before sharing a URL.
